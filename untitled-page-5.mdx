**在将代理集成至 BP Proxy Switcher 之前，请确保代理服务已正确配置并处于可正常使用状态。**

**提示**：使用插件前，请先将您的本地 IP 地址添加至 IP 白名单。

具体操作步骤如下：

1. 单击 BP Proxy Switcher 图标，选择“编辑”（Edit）。
   <Frame>
     ![Image](/images/image-87.png "Image")
   </Frame>
2. 在代理类型中选择 HTTP(S)，输入通过 API 获取的 IP 地址和端口（格式为 ip:port），然后点击“确定”（OK）。
   <Frame>
     ![Image](/images/image-88.png "Image")
   </Frame>
3. 配置成功后，BP Proxy Switcher 图标将亮起；若图标未亮起，则表示配置未生效，需重新执行上述设置。
   <Frame>
     ![Image](/images/image-89.png "Image")
   </Frame>

完成以上步骤后，您即成功实现了 BP Proxy Switcher 与代理的集成，为网络连接提供了更安全、更灵活的选择。
