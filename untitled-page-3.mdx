title: "Firefox 代理集成指南 "
---

**在将代理集成到 Firefox 之前，请先确保代理服务本身已正确配置并可正常使用。以下是具体操作步骤：**

1. 在 Firefox 中安装代理扩展程序，例如 SwitchyOmega，也可选用其他常用扩展。请在 Firefox 网上应用店中搜索并添加。
2. 下载所需的 Firefox 扩展包，解压后找到扩展文件夹。
3. 点击 Firefox 地址栏右侧的三个点（菜单按钮），选择“扩展程序”，再点击“管理扩展程序”。
4. 在打开的扩展管理页面中，开启“开发者模式”开关，然后点击 Firefox 地址栏右侧的扩展程序图标，打开已安装的代理扩展。
5. 在代理扩展中添加代理配置，包括代理协议、代理服务器地址、端口、用户名和密码等信息，并保存设置。一定要点击最右侧的小锁图标输入账号密码

6. 通过浏览器访问检测网站，若显示的当前 IP 地址与代理 IP 一致，则说明代理设置成功。

按照以上步骤，您即可顺利完成 Firefox 与代理的集成，实现更安全、更灵活的网络连接。
