**Before integrating a proxy into Edge, ensure that the proxy service has been correctly configured and is functioning properly.**

The specific steps are as follows:

1. Launch Microsoft Edge.
2. Click the three-dot menu icon (···) on the right side of the address bar.
3. From the drop-down menu, select **Extensions**.
   <Frame>
     ![Image](/images/image-105.png "Image")
   </Frame>
4. Click **Get extensions for Microsoft Edge** to access the extensions store homepage.
5. In the store, search for proxy extensions (such as SwitchyOmega or other commonly used ones) and add them to Edge.
6. Once the installation is complete, click the extension icon on the right side of the Edge address bar to open the installed proxy extension.
   <Frame>
     ![Image](/images/image-106.png "Image")
   </Frame>
7. In the proxy extension's configuration interface, fill in the proxy protocol, proxy server address, port number, username, password, and other required information, then save your changes.
8. After configuration, access an IP detection website through your browser. If the displayed current IP address matches the configured proxy IP, the proxy setup is successful.

By following the above steps, you will successfully complete the integration of Edge with the proxy, providing a more secure and flexible option for your network connection.
