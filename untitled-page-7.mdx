---
title: "Microsoft Edge 代理集成指南 "
---

**在将代理集成至 Edge 之前，请确保代理服务已正确配置并处于可正常使用状态。**

具体操作步骤如下：

1. 启动 Microsoft Edge 浏览器。

2. 单击地址栏右侧的三点菜单图标（···）。

3. 在下拉菜单中，选择“扩展”（Extensions）。

4. 点击“获取 Microsoft Edge 扩展”，进入扩展商店主页。

5. 在扩展商店中搜索代理类扩展程序（如 SwitchyOmega 或其他常用扩展），并将其添加至 Edge。

6. 安装完成后，单击地址栏右侧的扩展程序图标，打开已安装的代理扩展。

7. 在代理扩展的配置界面中，依次填写代理协议、代理服务器地址、端口号、用户名及密码等信息，并保存设置。

8. 配置完成后，通过浏览器访问 IP 检测网站，若当前显示的 IP 地址与所设代理 IP 一致，则表明代理设置成功。

完成以上步骤后，您即成功实现了 Edge 与代理的集成，为网络连接提供了更安全、更灵活的选择。
